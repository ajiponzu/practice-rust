# Review Markdown Generator

成果物を含むプロジェクト直下の `review/` に，対応する名前のレビュー文書を作成する．設計フェーズでは `review/design.md`，実装フェーズでは `review/implement.md`，テストケース設計フェーズでは `review/testcase.md`，テストコード実装フェーズでは `review/testcode.md` を使う．

## 必須の構成

- 現在の判定と次の作業
- 観点・配点・得点・根拠の採点表
- `ステータス`，`指摘箇所`，`質問・指摘内容`，`人間の回答`，`AI の確認` を含む回答表

## 運用

- 既存のレビュー文書は上書きせず，AI が表と点数を更新する．
- 状態は `未回答`，`回答済み`，`承認`，`差し戻し`，`修正中`，`却下` を使う．
- 人間の回答後，AI は承認または差し戻しを記録する．
- 全項目が解決するまで，AI は次工程への移行を提案しない．
