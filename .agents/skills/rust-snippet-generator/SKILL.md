# Rust Exercise Generator

`.agents/guide/meta/pair-learning-flow.md` を読んで進める．

## 出力

- 課題文，開始コードまたは対象コード，完了条件，採点観点
- 必要ならヒントを3段階と，追加の発展課題

## 進め方

1. 練習テーマ，難易度，形式（実装・穴埋め・読解・デバッグ・説明）を確認する．
2. 1つの概念に絞った小課題を作る．初回は解答を伏せる．
3. 人間の回答後，コンパイル可否と理解度を区別してレビュー・採点する．
4. 解答例は，人間が希望した場合または採点後の振り返りとして提示する．

## 運用

- 標準ライブラリを優先し，外部クレートは明示的に必要な場合だけ使う．
- 課題の採点は正確性，所有権・型の理解，可読性，説明のうち関係する観点に限定する．
