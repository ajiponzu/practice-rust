# Markdown Exercise Generator

`.agents/guide/meta/pair-learning-flow.md` を読んで進める．

## 進め方

1. 練習対象（表，数式，図）と，表したい内容を確認する．
2. 人間が書くべき Markdown の空のひな形，完了条件，採点観点を提示する．
3. 人間の提出後，構文の正確性，情報の明確さ，図の読みやすさをレビューする．
4. 希望があれば，解答例と発展課題を提示する．

## 運用

- 初回は完成 Markdown を提示しない．
- Mermaid は動作しやすい基本構文から扱い，課題に無関係な装飾を増やさない．
