# コミットメッセージガイド

gitのコミットメッセージガイドを記載する

## コミットメッセージの書き方

- 下記に従う

```
<type>: <概要>

[本文（必要な場合）]
```

| type       | 用途         |
| ---------- | ------------ |
| `feat`     | 新機能       |
| `fix`      | バグ修正     |
| `refactor` | リファクタ   |
| `test`     | テスト       |
| `docs`     | ドキュメント |
| `chore`    | ビルド・設定 |

Issue を使う場合のみ，必要に応じて本文に `Refs #<issue番号>` を追加する．
