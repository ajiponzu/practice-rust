# 課題：ログ集計 CLI

## 基本情報

- クレート名：`log-counter`
- 作成方法：`cargo new log-counter`（バイナリ）
- 形式：新規実装
- 標準所要時間：30〜90分

## 背景

簡単な運用ログを素早く把握するため、複数行のログ文字列からログレベル別の件数を集計する CLI を作成する。

## 入力例

```text
INFO server started
WARN cache is almost full
INFO request completed
ERROR database unavailable
WARN retry scheduled
```

## 機能

- 各行の先頭語をログレベルとして扱う。
- `INFO`、`WARN`、`ERROR` の件数を数える。
- 空行は無視する。
- `DEBUG` など未知のログレベルはエラーとして扱う。
- 集計結果を次の形式で表示する。

```text
INFO: 2
WARN: 2
ERROR: 1
```

## 制約

- 外部クレートを使わない。
- 集計処理を `main` から分離した関数にする。
- 未知レベル時は `Result` で呼び出し元へ返す。
- `HashMap` を使わず、ログレベルを表す独自の構造体またはタプルで保持する。

## 受け入れ条件

- 正常なログで正しい件数を表示できる。
- 空行を無視できる。
- 未知レベルを含む入力で、内容の分かるエラーを表示できる。
- `cargo fmt` と `cargo clippy` を通せる。
